# Сонник — личный Telegram-бот

Вы пишете боту, что вам приснилось, и он отвечает коротким толкованием в двух абзацах:

1. **Что говорят сонники.** 2–3 подходящие традиции: Миллер, Цветков, традиция Ванги.
2. **Взгляд психологии.** Фрейд, Юнг или когнитивный подход Холла и в конце один мягкий вопрос о себе.

Все сны и толкования сохраняются в личный дневник на компьютере, где работает бот.

> Толкования носят развлекательно-рефлексивный характер. Это не предсказание будущего, не медицинский совет и не диагноз. Тексты сонников бот не цитирует: он пересказывает их дух своими словами.

## Команды в Telegram

- просто текст сна — получить толкование;
- `/history` — последние 5 снов;
- `/forget` — удалить все записи (бот спросит подтверждение);
- `/help` — справка.

Бот личный: он отвечает только тем Telegram-аккаунтам, которые указаны в настройках.

## Как включить и выключить

- **Windows:** включить — двойной щелчок по `start.bat`, выключить — `stop.bat`.
- **macOS / Linux:** включить — `start.sh`, выключить — `stop.sh`.

При первом включении бот сам установит всё нужное (нужен Python 3.11 или новее).

Бот работает, только пока включён компьютер, на котором он запущен. Чтобы он отвечал круглосуточно, его нужно перенести на сервер. Claude Code может помочь и с этим.

## Если бот перестал отвечать

1. Выключите и снова включите бота (`stop`, потом `start`).
2. Иногда серверы Google перегружены: бот честно скажет, что не смог ответить. Подождите минуту и отправьте сон ещё раз.
3. Если не помогло, откройте Claude Code в этой папке и напишите: «Бот-сонник не отвечает, разберись».

## Как что-то поменять

- **Список сонников и психологов** хранится в `config/traditions.yaml`: можно убрать, добавить или переописать традицию.
- **Стиль и правила ответа** хранятся в `prompts/interpreter.md`.
- **Токены, модель и список разрешённых пользователей** хранятся в `.env`. Этот файл не попадает в GitHub.

Самому править файлы не нужно: откройте Claude Code в папке проекта и напишите, что хотите, например:
«Добавь сонник Лоффа» или «Сделай ответы короче».

## Для разработчика

```
pip install -r requirements-dev.txt
pytest
ruff check .
```

Python 3.11+, aiogram 3, Google Gemini (`google-genai`), SQLite (`aiosqlite`). В журналах (`logs/`) текст снов не сохраняется.
