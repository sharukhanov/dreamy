# Сонник — личный Telegram-бот

Вы пишете боту, что вам приснилось, и он отвечает коротким толкованием в двух абзацах:

1. **Что говорят сонники.** 2–3 подходящие традиции: Миллер, Цветков, традиция Ванги.
2. **Взгляд психологии.** Фрейд, Юнг или когнитивный подход Холла и в конце один мягкий вопрос о себе.

Все сны и толкования сохраняются в личный дневник на компьютере, где работает бот.

> Толкования носят развлекательно-рефлексивный характер. Это не предсказание будущего, не медицинский совет и не диагноз. Тексты сонников бот не цитирует: он пересказывает их дух своими словами.

## Команды в Telegram

- просто текст сна — получить толкование;
- `/sonnik` — выбрать до 3 сонников (или оставить случайные);
- `/history` — последние 5 снов;
- `/forget` — удалить все записи (бот спросит подтверждение);
- `/help` — справка.

Ботом может пользоваться любой человек. Каждый видит только свои сны. Чтобы бесплатный лимит Gemini не закончился, один человек может отправить не больше 10 снов в сутки (у владельца ограничений нет). В группах бот молчит и работает только в личных сообщениях.

Кто может пользоваться ботом, задаётся в секрете `ALLOWED_USER_IDS` на Cloudflare: `*` — все, `*,123` — все, а у id 123 нет лимита, `123,456` — только эти люди. Лимит — `DAILY_LIMIT` в `worker/wrangler.toml`.

## Где работает бот

Бот работает круглосуточно и бесплатно на **Cloudflare Workers**, так что ваш компьютер для этого не нужен. Telegram сам передаёт ему каждое сообщение, а дневник снов хранится в базе Cloudflare (D1).

- Адрес бота на Cloudflare: https://dream-bot.dream-bot-worker.workers.dev
- Код этой версии лежит в папке `worker/`.
- Ключи (токен Telegram, ключ Gemini, список доступа) хранятся в зашифрованных настройках Cloudflare, а не в репозитории.

Если серверы Google с моделью недоступны, бот отвечает: «Временно не удаётся подключиться к модели…». Просто повторите попытку через пару минут.

### Если бот перестал отвечать

Откройте Claude Code в этой папке и напишите: «Бот-сонник не отвечает, разберись».

### Запасной вариант: запуск на своём компьютере

В проекте осталась и обычная версия бота на Python (папка `bot/`). Её можно запустить на своём компьютере файлом `start.bat` (Windows) или `start.sh` (macOS/Linux), выключить `stop.bat` / `stop.sh`. Перед этим её нужно отключить от Cloudflare (попросите Claude Code). Можно развернуть её и на сервере Google Cloud (`deploy/gcloud_deploy.sh`).

## Как что-то поменять

- **Список сонников и психологов** хранится в `config/traditions.yaml`: можно убрать, добавить или переописать традицию. Выбор сонников кнопками есть только в Cloudflare-версии.
- **Стиль и правила ответа** хранятся в `prompts/interpreter.md`.
- **Модель Gemini** задаётся в `worker/wrangler.toml`.

После любой правки бота нужно заново выложить на Cloudflare (`cd worker && npx wrangler deploy`). Самому править файлы не нужно: откройте Claude Code в папке проекта и напишите, что хотите, например:
«Добавь сонник Лоффа» или «Сделай ответы короче».

## Для разработчика

Cloudflare-версия (`worker/`): JavaScript, webhook, D1, Gemini REST API.

```
cd worker && npm ci && npm test      # тесты
npx wrangler deploy                  # выложить (нужен CLOUDFLARE_API_TOKEN)
```

Python-версия: Python 3.11+, aiogram 3, `google-genai`, `aiosqlite`.

```
pip install -r requirements-dev.txt && pytest && ruff check .
```

Ни одна из версий не пишет текст снов в журналы.
